description=Gives QGIS the look and layout of ArcMap 10: classic menu bar, Standard/Tools/Editor toolbars, Table Of Contents with List By views, Catalog/Search/ArcToolbox panes, Data/Layout view buttons, ArcMap status bar, attribute table and symbology defaults. One click on, one click off.
about=ArcMap Skin rearranges and restyles the QGIS interface so that users coming from ArcMap 10.x feel at home: an ArcMap-style menu bar (File, Edit, View, Bookmarks, Insert, Selection, Geoprocessing, Customize, Windows, Help), dockable Standard, Tools, Editor, Draw, Layout and Labeling toolbars built from QGIS's own tools, a Table Of Contents with List By Drawing Order / Source / Visibility / Selection, Catalog, Search and ArcToolbox panes, Data View / Layout View buttons, an ArcMap-like status bar and attribute table, ArcMap-style default symbology and colour ramps, and a flat, redrawn icon theme. Every change is recorded and reverted when the look is switched off. ArcMap Skin is an independent project and is not affiliated with, sponsored or endorsed by Esri. All icons are original artwork or derived from QGIS icons (GPL).

    - Fix the ArcMap look toggle being deleted by the first re-apply.

    - Dark ArcMap theme with light icon variants.

    - Advanced Editing and Topology toolbars, Time Slider pane, Catalog Contents/Preview/Description tabs, Create Graph in the Table window, ArcMap Symbol Selector wording.
    - Turkish, French and Spanish translations (plus Arabic).
